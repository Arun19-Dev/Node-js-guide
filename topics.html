Introduction to Node.js

Definition

Node.js is a cross-platform, open-source JavaScript runtime environment built on Chrome's V8 engine. It executes JavaScript code outside a web browser.

Tanglish

"Node.js na oru JavaScript runtime environment — Chrome V8 engine use panni JavaScript code-ah browser-ku veliya run pannum. Cross-platform na Windows, Mac, Linux-la ellaam run aagum."

Features of Node.js
  • Asynchronous & Non-blocking: Doesn't wait for slow operations
  • Single-threaded with Event Loop: Handles many connections efficiently
  • Fast execution: V8 compiles JS to machine code
  • npm ecosystem: 2M+ packages available
  • Cross-platform: Works on Windows, Mac, Linux
  • Full-stack JavaScript: Same language for frontend + backend
Advantages
AdvantageExplanation
FastV8 engine compiles JS directly to machine code
ScalableNon-blocking I/O handles many concurrent connections
Large ecosystemnpm has 2M+ reusable packages
One languageJavaScript for both client and server
Active communityHuge community support and resources
Limitations
  • Not ideal for CPU-intensive tasks (heavy computations)
  • Callback complexity (can be solved with Promises/async-await)
  • Single-threaded nature can be a bottleneck for CPU-heavy work
Real-World Use Case

Netflix uses Node.js to serve millions of streaming requests. LinkedIn uses it to handle mobile API traffic. Both chose Node.js for its speed and efficiency with I/O operations.

Common Mistake

Don't confuse Node.js with a framework. Node.js is a runtime. Express.js is a framework built on top of Node.js.

Arrow Functions
JavaScript 
// Traditional function
function greet(name) {
    return "Hello " + name;
}

// Arrow function (shorter syntax)
const greet = (name) => {
    return "Hello " + name;
};

// Even shorter for single expression

Callbacks, Promises & Async/Await
JavaScript 
// Callback: function passed as an argument
function fetchData(callback) {
    setTimeout(() => {
        callback("Data received!");
    }, 1000);
}
fetchData((data) => console.log(data));

// Promise: cleaner way to handle async operations
function fetchData() {
    return new Promise((resolve, reject) => {
        setTimeout(() => resolve("Data received!"), 1000);
    });
}
fetchData().then(data => console.log(data));

// Async/Await: cleanest way (looks like sync code)
async function getData() {
    try {
        const data = await fetchData();
        console.log(data);
    } catch (error) {
        console.error("Error:", error);
    }
}
getData();
Tanglish

"Callback na oru function-ah vera function-ku argument-ah pass panrathu. Promise na 'future-la value varum' nu oru object. Async/await na Promise-ah clean-ah ezhudha oru shortcut — synchronous maari paakkum aana actually asynchronous-ah run aagum."

Destructuring & Spread
JavaScript 
// Object Destructuring
const student = { name: "Arun", age: 22, dept: "CSE" };
const { name, age } = student;
console.log(name); // "Arun"

// Array Destructuring
const colors = ["red", "green", "blue"];
const [first, second] = colors;
console.log(first); // "red"

// Spread Operator
const arr1 = [1, 2, 3];
const arr2 = [...arr1, 4, 5]; // [1, 2, 3, 4, 5]

// Rest Operator
function sum(...numbers) {
    return numbers.reduce((a, b) => a + b, 0);
}
console.log(sum(1, 2, 3, 4)); // 10

Understanding Modules

Definition

A module is a reusable piece of code that can be imported into other files. Node.js uses modules to organize code into separate files and reuse functionality.

Tanglish

"Module na reusable code piece. Oru file-la ezhudha code-ah vera file-la import panni use pannalam. Idhu code-ah organize panna help pannum."

Creating & Using Local Modules
math.js (Local Module) 
// math.js - Creating a local module
function add(a, b) {
    return a + b;
}

function subtract(a, b) {
    return a - b;
}

// Export functions so other files can use them
module.exports = { add, subtract };
app.js (Using the module)

console.log(math.add(5, 3));      // 8
console.log(math.subtract(10, 4)); // 6

Sync vs Async

JavaScript 
const fs = require("node:fs");

// Synchronous - blocks execution until file is read
const data = fs.readFileSync("file.txt", "utf-8");
console.log(data);
console.log("This runs AFTER file is read");

// Asynchronous - does NOT block
fs.readFile("file.txt", "utf-8", (err, data) => {
    if (err) {
        console.error("Error:", err.message);
        return;
    }
    console.log(data);
});
console.log("This runs BEFORE file is read!");
Tanglish

"Synchronous na one-by-one run aagum — oru line mudiyama next line run aagaadhu. Asynchronous na slow operation background-la run aagum, meanwhile vera code execute aagum."

Event Emitters
JavaScript 
const EventEmitter = require("node:events");

const emitter = new EventEmitter();

// Listen for an event
emitter.on("greet", (name) => {
    console.log(`Hello, ${name}!`);
});

// Emit (trigger) the event
emitter.emit("greet", "Arun"); // Hello, Arun!

What is Express.js?

Express.js is a minimal, flexible web framework for Node.js. It simplifies server creation, routing, and middleware management compared to using the raw http module.

Tanglish

"Express.js na Node.js-ku oru web framework. Raw http module use pannina routing manually pannanum — Express use pannina app.get(), app.post() nu simple-ah route create pannalam."

express-server.js 
const express = require("express");
const app = express();

// Middleware to parse JSON request bodies
app.use(express.json());

// GET endpoint - Home
app.get("/", (req, res) => {
    res.json({ message: "Welcome to Express!" });
});

// GET endpoint - All students
app.get("/students", (req, res) => {
    const students = [
        { id: 1, name: "Arun", dept: "CSE" },
        { id: 2, name: "Priya", dept: "ECE" }
    ];
    res.json(students);
});

// GET endpoint - Student by ID (Route Parameter)
app.get("/students/:id", (req, res) => {
    const studentId = req.params.id;
    res.json({ message: `Student ID: ${studentId}` });
});

// POST endpoint - Add student
app.post("/students", (req, res) => {
    const newStudent = req.body;
    res.status(201).json({
        message: "Student added!",
        student: newStudent
    });
});

// 404 handler (must be last)
app.use((req, res) => {
    res.status(404).json({ message: "Route not found" });
});

// Start server
app.listen(3000, () => {
    console.log("Express server running on port 3000");
});
Why Express over raw http?

Compare the multiple endpoints server from fundamentals.html (using if-else chains) with Express routes above. Express makes it cleaner, more readable, and adds powerful features like middleware, route parameters, and built-in JSON parsing.

SQL vs NoSQL

SQL databases (MySQL, PostgreSQL) store data in tables with rows and columns. NoSQL databases (MongoDB) store data in flexible JSON-like documents. MongoDB is popular with Node.js because both use JavaScript-like syntax.

Tanglish

"SQL database na table format-la data store pannum. NoSQL (MongoDB) na JSON-like documents-la store pannum. MongoDB Node.js-kku best suit aagum — rendukkum JavaScript-maari syntax."

    const data = JSON.parse("invalid json");
} catch (error) {
    console.error("Parse error:", error.message);
}

// Async error handling
async function fetchData() {
    try {
        const response = await fetch("https://api.example.com/data");
        const data = await response.json();
        return data;
    } catch (error) {
        console.error("Fetch error:", error.message);
        throw error; // Re-throw if needed
    }
}

// Unhandled rejection handler (safety net)
process.on("unhandledRejection", (reason, promise) => {
