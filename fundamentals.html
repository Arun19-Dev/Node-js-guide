Learn by Understanding – What Node.js is, how it works, and build your first server

1

What is Node.js?

Simple English

Node.js is a JavaScript runtime environment that allows you to run JavaScript code outside the web browser. Normally, JavaScript runs only inside browsers like Chrome, Firefox, or Edge. But Node.js lets you use JavaScript to build servers, work with files, connect to databases, and much more — all on your computer or a server.

Node.js was created by Ryan Dahl in 2009. He took Google Chrome's V8 JavaScript engine (the same engine that runs JavaScript in Chrome) and wrapped it in a C++ program so JavaScript could run outside the browser.

Tanglish

"Node.js na JavaScript code-ah browser-ku veliya execute panna help panra JavaScript runtime. Normal-ah JavaScript browser-la run aagum. Aana Node.js use pannina namma computer-la JavaScript use panni server create pannalam, files-ah read pannalam, database connect pannalam."

"Chrome browser-la irukkura V8 engine-ah eduthu, adhula JavaScript run aagura maari Node.js-la pannirukkanga. Adhanala browser-ku veliyavum JavaScript use panna mudiyum."

Real-World Example

Think of it like this: JavaScript in a browser is like a cook who can only work in one specific kitchen (the browser). Node.js gives that cook a portable stove — now they can cook anywhere (on any computer, on any server).

Why Do We Use Node.js?

Simple English

Node.js is popular because it allows developers to use one language (JavaScript) for both frontend and backend. It is fast, lightweight, and designed for building web servers and APIs.

Tanglish

"Node.js use pannura main reason na — frontend-layum backend-layum same JavaScript language use pannalam. Server create panna, API build panna, database handle panna, real-time chat application build panna — ellame JavaScript-la pannalam."

What Can You Build with Node.js?

Web Servers

Create servers that respond to browser requests

REST APIs

Build APIs to send and receive JSON data

Real-Time Apps

Chat apps, live notifications, online games

File Handling

Read, write, and manage files on the server

Database Operations

Connect to MongoDB, MySQL, PostgreSQL

npm Packages

Access 2M+ reusable packages from npm

When to Choose Node.js

Use Node.js when you need to build APIs, handle many concurrent connections (like chat apps), or want to use JavaScript for backend development. It's great for I/O-heavy tasks but not ideal for CPU-intensive work like complex mathematical computations or video encoding.

3

Node.js Architecture

Simple English

Node.js uses a special architecture that makes it fast and efficient. Here are the key components:

V8 Engine

The V8 engine is Google's open-source JavaScript engine written in C++. It compiles JavaScript directly to machine code (binary code that the computer can execute directly), making it extremely fast.

Tanglish

"V8 engine na Google develop panna JavaScript engine. Idhu JavaScript code-ah directly machine code-ah convert pannidum. Adhanaala fast-ah run aagum. Chrome browser-layum Node.js-layum same V8 engine dhaan use aagudhu."

Event Loop

The event loop is the heart of Node.js. It continuously checks if there are any tasks to execute. When Node.js receives a request, it doesn't wait for one task to finish before starting another — it handles multiple tasks by delegating slow operations (like reading files or database queries) to background workers and continues processing other requests.

Tanglish

"Event loop na Node.js-oda core concept. Idhu oru waiter maari — oru table-oda order eduthutu, adhu ready aagura varaikkum vera table-ku poyi order eduppaan. Wait panna maattan. Adhey maari Node.js oru request varudhunna, adhu mudiyura varaikkum wait pannama vera request-ah handle pannum."

Call Stack

The call stack is where JavaScript keeps track of what function is currently running. When a function is called, it's added to the stack. When it finishes, it's removed from the stack. JavaScript can only execute one function at a time (single-threaded).

Non-Blocking I/O

Node.js uses non-blocking I/O, which means it doesn't wait for slow operations (like reading a file or querying a database) to finish. Instead, it continues executing other code and processes the result when the operation completes.

Tanglish

"Non-blocking I/O na — Node.js file read pannumbodhu adhu mudiyura varaikkum wait pannama, vera code-ah execute pannidum. File read aana udan callback function call aagum. Idhanaala fast-ah work aagum."

Single-Threaded but Powerful

JavaScript itself runs on a single thread (one task at a time). But Node.js uses background worker threads (handled by libuv, a C library) for heavy I/O operations. So while JavaScript code runs on one thread, file reads, database queries, and network requests happen in the background on separate threads.

Remember

Node.js is single-threaded for JavaScript execution, but uses multiple threads in the background for I/O operations. This is what makes it efficient for handling many concurrent connections.

Install Node.js

Simple English

To use Node.js, you need to download and install it on your computer. Node.js comes with npm (Node Package Manager) automatically.

Step 1: Download Node.js

Go to the official website: https://nodejs.org/

You'll see two download options:

VersionDescriptionRecommended For
LTS (Long Term Support)Stable, well-tested versionBeginners and production use
CurrentLatest features, may have bugsDevelopers who want newest features
Tanglish

"LTS version na stable version — bugs kammi irukkum, production-la use pannalam. Current version na latest features irukkum aana bugs irukkalam. Beginners-ku LTS download pannunga."

Step 2: Install on Windows

  1. Download the .msi installer from nodejs.org
  2. Double-click the downloaded file
  3. Click "Next" through the installation wizard
  4. Accept the license agreement
  5. Keep the default installation path
  6. Click "Install" and wait for completion
  7. Click "Finish"

Step 3: Verify Installation

Open your terminal (Command Prompt, PowerShell, or VS Code terminal) and run:

Terminal 
node -v
Expected Output 
v20.11.1
Tanglish

"node -v command run pannuna, Node.js version number kaatum. Version number vandhaa, installation correct-ah aaiduchu."

Now check npm:

Terminal 
npm -v
Expected Output 
10.2.4
Tanglish

"npm -v run pannuna npm version kaatum. npm na Node Package Manager — third-party packages install panna use pannuvom."

Common Issue

If you see 'node' is not recognized as an internal or external command, it means Node.js was not added to your PATH during installation. Try restarting your terminal or reinstalling Node.js.

Create a Basic Node.js Server

Simple English

Now let's create an HTTP server. This is a program that listens for requests from web browsers and sends back responses. Node.js has a built-in module called http that lets you create servers without installing anything extra.

Tanglish

"HTTP server na browser-lirundhu vara request-ah listen panni, response anuppura program. Node.js-la http nu oru built-in module irukkum — adhula createServer() function use panni server create pannalam."

The Complete Code

server.js 
const http = require("node:http");

const server = http.createServer((req, res) => {
    res.writeHead(200, {
        "Content-Type": "text/plain"
    });

    res.end("Hello Students! Welcome to Node.js");
});

server.listen(3000, () => {
    console.log("Server running at http://localhost:3000");
});

Line-by-Line Explanation

CodeEnglish ExplanationTanglish
const http = require("node:http"); Import the built-in HTTP module. require() is the CommonJS way to load modules in Node.js. "Node.js-oda built-in http module-ah load panrom. require() function use panni module import pannuvom."
http.createServer((req, res) => { ... }) Create a new HTTP server. The callback function runs every time a request comes in. req = request info, res = response object. "Pudhu server create panrom. Oru request varum bodhu callback function run aagum. req na request details, res na response object."
res.writeHead(200, { "Content-Type": "text/plain" }) Set the HTTP status code to 200 (OK) and tell the browser the response is plain text. "Status code 200 (success) set panrom. Content-Type header set panni browser-ku 'idhu plain text' nu solrom."
res.end("Hello Students! Welcome to Node.js") Send the response text and end the response. "Response text anuppi, response-ah end panrom."
server.listen(3000, () => { ... }) Start the server on port 3000. The callback runs when the server is ready. "Server-ah port 3000-la start panrom. Server ready aana udan callback function run aagum."

What is a Port?

Tanglish

"Port na oru number — computer-la ella program-kum oru unique port assign aagum. Port 3000 na namma server listen panra 'door number' maari. Browser-la localhost:3000 nu type pannina, adhu namma server-oda door-ah knock pannum."

How to Run and Test

Terminal 
node server.js
Terminal Output 
Server running at http://localhost:3000

Now open your browser and go to: http://localhost:3000

You should see: "Hello Students! Welcome to Node.js"

How to Stop the Server

Press Ctrl + C in the terminal to stop the server. The server runs continuously until you manually stop it.

What Is an Endpoint?

Simple English

An endpoint is a specific URL on a server that performs a specific action. When you type a URL in a browser, the browser sends a request to the server at that endpoint, and the server sends back a response.

Tanglish

Create Multiple Endpoints

Simple English

Now let's create a server with multiple endpoints. Each endpoint will return a different response based on the URL the user visits.

Tanglish

"Ipo namma oru server create pannuvom — adhula multiple endpoints irukkum. / endpoint home page kaatum, /about about page kaatum, /students student data return pannum. Unknown URL vandha 404 error return pannum."

Server with Multiple Endpoints

server.js 
const http = require("node:http");

const server = http.createServer((req, res) => {
    res.setHeader("Content-Type", "application/json");

    if (req.method === "GET" && req.url === "/") {
        res.writeHead(200);
        res.end(JSON.stringify({
            message: "Welcome to Node.js"
        }));
    } else if (req.method === "GET" && req.url === "/about") {
        res.writeHead(200);
        res.end(JSON.stringify({
            message: "This is the About endpoint"
        }));
    } else if (req.method === "GET" && req.url === "/students") {
        res.writeHead(200);
        res.end(JSON.stringify([
            { id: 1, name: "Arun" },
            { id: 2, name: "Priya" }
        ]));
    } else if (req.method === "GET" && req.url === "/contact") {
        res.writeHead(200);
        res.end(JSON.stringify({
            email: "trainer@example.com",
            phone: "Not provided"
        }));
    } else {
        res.writeHead(404);
        res.end(JSON.stringify({
            message: "Endpoint not found"
        }));
    }
});

server.listen(3000, () => {
    console.log("Server running on port 3000");
});

Key Explanations

setHeader vs writeHead

res.setHeader() sets a single header. res.writeHead() sets the status code and can set multiple headers at once. In this example, we set the Content-Type once using setHeader and then set the status code separately using writeHead.

JSON.stringify()

JSON.stringify() converts a JavaScript object or array into a JSON string. This is needed because res.end() only sends strings or Buffers, not JavaScript objects directly.

Tanglish

"req.url na browser-la user type panna URL path. req.method na GET, POST maari HTTP method. if-else use panni ovvoru URL-kum vera vera response anuppurom. Unknown URL vandha 404 status code anuppurom — 'not found' nu."

How to Test

  1. Run node server.js in your terminal
  2. Open your browser and visit each endpoint:
    • http://localhost:3000/
    • http://localhost:3000/about
    • http://localhost:3000/students
    • http://localhost:3000/contact
    • http://localhost:3000/xyz (should show 404)
Important Note

This is a demonstration using Node.js's built-in HTTP module. In real projects, you would use a framework like Express.js which makes routing much simpler. We'll learn Express.js in the Topics page (Module 10).
